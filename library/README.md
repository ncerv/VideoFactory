# library

Biblioteca de recursos 2D reutilizables entre proyectos.

| Carpeta | Contenido |
|---|---|
| `art-styles/` | Registro de estilos (`registry.json`) y, más adelante, la guía de cada estilo |
| `compositions/` | Composiciones HyperFrames reutilizables (escenas tipo, títulos, créditos) |
| `motion/` | Patrones de animación GSAP (entradas, salidas, cámara 2D, paralaje) |
| `materials/` | Texturas y tratamientos 2D (papel, tinta, grano, tela) |
| `transitions/` | Transiciones entre escenas |
| `components/` | Componentes visuales (subtítulos, rótulos, marcos) |

Todo el contenido es exclusivamente 2D.
