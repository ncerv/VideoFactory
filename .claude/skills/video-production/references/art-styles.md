# Estilos artísticos (2D)

El registro oficial está en `library/art-styles/registry.json` del repositorio VideoFactory. Todos los estilos se producen **exclusivamente en 2D**.

| Id | Nombre | Nota |
|---|---|---|
| `woodblock-print` | Woodblock Print | |
| `pixel-art` | Pixel Art | |
| `noir-comic` | Noir Comic | |
| `1930s-cartoon` | 1930s Cartoon | |
| `brick-toy` | Brick Toy | Evoca volumen: se resuelve en 2D |
| `clay-diorama` | Clay Diorama | Evoca volumen: se resuelve en 2D |
| `knitted-puppet` | Knitted Puppet | Evoca volumen: se resuelve en 2D |
| `ps2-style` | PS2 Style | Evoca volumen: se resuelve en 2D |
| `sumi-ink` | Sumi Ink | |
| `painted-codex` | Códice pintado | |
| `paper-cutout` | Paper Cutout | |

En los estilos que evocan volumen, la sensación material se consigue con ilustración, capas, texturas, sombras proyectadas planas y paralaje 2D. Nunca con geometría ni modelos 3D.

Por ahora todos los estilos están en estado `registered`. Sus guías visuales, paletas y recursos se añadirán en `library/art-styles/<id>/`.
